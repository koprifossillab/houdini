# ② QA 독립 검증 의뢰 — TC-DASH-009 0.3.1-rc.1 "이 컴퓨터 전용 상세 화면" (④ 관제실 담당 · 2026-11-11)

운영 0.3.0 변경 없음 · nginx·운영 .env 변경 없음 · 배포 없음

## 배경
- 소유자 결정(11/10): "외부 접근 확인하지 말고, 이 컴퓨터로만 들어갈 것". 내부망·VPN 상세 공개(B안)는 제외한다.
- 따라서 인증이 꺼져 있을 때 상세 화면은 **이 컴퓨터에서 온 요청에만** 보여 준다. 그 밖의 요청에는 0.3.0 공개 화면을 그대로 준다.

## 판정 규칙 (server.mjs `localViewer`)
- 상세 화면은 아래 세 조건을 모두 만족할 때만 나간다.
  1. `HPC_LOCAL_DETAIL` 이 0 이 아니다 (기본 켜짐, `0` 이면 끔).
  2. 소켓이 신뢰 프록시다. 운영에서는 docker 게이트웨이, 스테이징에서는 루프백.
  3. `X-Real-IP` 가 127.0.0.1 또는 ::1 이다. 헤더가 없는 경우는 nginx 를 거치지 않고 루프백 전용 포트로 직접 들어온 것이므로 이 컴퓨터로 본다.
- `X-Forwarded-For` 와 `Forwarded` 는 쓰지 않는다. nginx 가 클라이언트가 보낸 값 뒤에 덧붙이기 때문이다.
- 상세 화면은 0.2.2 상세 화면 + 0.3.0 "지금" 상세 + 비용(USD·KRW)·토큰 + 이력·인계 카드·사용자 조치다. 15분 지연 없이 10초 캐시로 갱신한다. 비밀정보 제거 규칙(sanitize)은 그대로다.
