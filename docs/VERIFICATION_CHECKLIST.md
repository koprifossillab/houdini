# 검증 준비 — 브라우저·화면 상태 (v0.1.1)

서버에서 자동으로 확인할 수 없는 항목을 사람이 브라우저로 확인하는 절차입니다.

## 1. 개발 인스턴스에 접속

- 개발 서버는 루프백에서만 엽니다(`HOST=127.0.0.1`, `HPC_AUTH=off`, TLS 없음). 바깥 네트워크에 열지 않습니다.
- 검증자 PC에서는 SSH 로컬 포워딩으로 붙습니다(`ssh -L 18097:127.0.0.1:18097 <서버>`).
- 붙은 뒤 `http://localhost:18097/Houdini/`을 엽니다.

| 인스턴스 | 실행 | 보이는 상태 |
|---|---|---|
| 실제 데이터 | `HPC_COLLECTOR_DIR … node server.mjs` | 정상 |
| 갱신 지연 | `HPC_DEMO=1 HPC_DEMO_STATE=stale` | 경고 띠, 팀 상태 '현재 확인 불가', 큐 실행 기록 '확인 불가' |
| 수집 자료 없음 | `HPC_DEMO=1 HPC_DEMO_STATE=missing` | 빨간 띠 '수집 자료 없음', 관련 프로세스 '확인 불가' |
| 수집 자료 오류 | `HPC_DEMO=1 HPC_DEMO_STATE=error` | 빨간 띠 '수집 자료 오류' |
| 예시 정상 | `HPC_DEMO=1` | 줄무늬 '예시 데이터' 띠가 늘 표시 |

## 2. 영상 재생 (Chrome · Edge)

- 대상: 미리보기 탭의 `TC-00-03 · 4개 조건 비교`
  - H.264 High, yuv420p, 레벨 3.1, 1024×576, 20 fps, 100프레임
  - 두 브라우저 모두 기본 지원 범위입니다.
- 확인할 것:
  - 재생
  - 탐색바로 2.5초 위치로 이동(서버가 206 Range 응답을 하는지)
  - 프레임 수와 fps 표시, 주의 문구 표시
- 서버 쪽은 확인을 마쳤습니다. 내보내는 바이트의 SHA-256이 기록과 일치하고, Range 요청에 206을 돌려줍니다.
- 이 서버의 헤드리스 Chromium(오픈소스 빌드)에는 H.264 디코더가 없어서 실제 재생은 사람이 확인해야 합니다.

## 3. 모바일 (390 px)

- 확인할 것:
  - 페이지 가로 스크롤 없음
  - 탭 줄만 가로로 스크롤됨
  - 실험 표는 표 영역 안에서만 가로로 스크롤됨
- CDP로 잰 값: `scrollWidth = 390`. 캡처는 `07_mobile`, `08_mobile_lab`입니다.
