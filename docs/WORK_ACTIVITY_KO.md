# TC-WORK 활동 연결
공개 HTTP 등록 API는 없다. 기존 SSH로 서명된 시작·진행·완료 기록을 제출한다.
PC 개인키는 PC 사용자/SYSTEM ACL로 보호하고 서버에는 공개키만 둔다. 웹 검증키는 이미지에 고정한다.
sequence/previous_hash 및 수신창 5분 검사, 동일 전송 재시도만 중복 없이 허용한다.
작업 요약·커밋·산출물 ID/해시·다음 작업만 공개하며 개인 경로·원문·인증정보는 거부한다.
서버 프로세스 실행은 UNKNOWN을 유지하고, 최근 15분 기록은 최근 활동 확인/작업 완료, 이후 활동 미확인으로 표시한다.
오래된 완료 기록은 마지막 완료 결과로 보존한다. 비정상 종료를 추정하지 않는다.
기존 TC-WORK HEAD/history만 갱신한다. PROD/QA 수집기·기록은 변경하지 않는다.
자동 hook/heartbeat는 설치하지 않는다. 실제 작업 체크포인트마다 같은 PC의 클라이언트 한 명령을 사용한다.
같은 PC 계정과 서명키가 유지되면 새 Work 세션도 같은 팀·순서를 이어간다. 키 분실·교체는 별도 관리가 필요하다.
SSH 계정과 서버 운영 권한자는 신뢰 경계다. 서명은 외부 입력과 키 없는 JSON 위조를 막으며 서버 관리자 자체의 공격을 방어하는 시스템은 아니다.
